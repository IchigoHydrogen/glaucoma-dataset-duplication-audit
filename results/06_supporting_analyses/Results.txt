[コメント14] FairVision の split ごとの重複と、分母の取り方
  split            候補対     画像一致       率   95%CI
  training         801      635   79.3%   [76.3, 82.0]
  validation       125      101   80.8%   [72.8, 87.3]
  test             376      295   78.5%   [74.0, 82.5]
  合計              1302     1031   79.2%

  → 重複率は split をまたいでほぼ一様（78〜81%）。
     コメント20 の前提（"the overlap is not uniform across splits"）は当てはまらない。
     名指しした3研究の開発・評価の分割がどこであっても、同程度に汚染されていることになる。

  FairVision 側の分母について
    本文は Harvard-GF 3300眼を分母に 1031眼（31%）と述べている。
    FairVision 側の分母は、対の fv_use 別の眼数（training 801 / validation 125 / test 376 = 1302）
    であり、これは「人口統計指紋が一致した候補対」の数である。
    FairVision の緑内障サブセット全体の眼数は、公開ファイルの緑内障ラベルから数える必要があり、
    本スクリプトの入力には含まれない。改訂時に census スクリプトから取得すること。
    （参考: results/20260720_paperB_fv_census/ にあるファイル: ['pairs.csv']）

[コメント34] cosine の閾値と実測の谷
  同一と判定した対の cosine 最小値      0.999945
  非同一と判定した対の cosine 最大値    0.8584
  閾値 0.99 と実測の谷のあいだに落ちた対 0 対
  0.86 と 0.99 のあいだに落ちた対        0 対

[コメント16] 非同一の271対をどう説明するか
  対数 271
  cosine: 中央値 0.444  四分位 0.318〜0.561  範囲 -0.162〜0.858
    cosine > 0.5: 106 対
    cosine > 0.7: 18 対
    cosine > 0.8: 3 対
    cosine > 0.85: 1 対

  仮説1「同じ患者の対側眼」の検定
    対側眼なら、左右反転した画像が高い類似度を示すはずである。
    左右反転で類似度が上がった対: 同一側 0 対 / 非同一側 49 対
    その 49 対の cosine: 中央値 0.171  最大 0.510
    → 反転しても類似度は低いままで、対側眼を支持しない。

  仮説2「同じ眼の別受診」の検定
    別受診なら網膜神経線維層厚は近い値を取り、cosine は中程度以上になるはずである。
    cosine が 0.85 を超えたのは 1 対のみで、中央値は 0.444 にとどまる。
    → 大半は別受診でも説明できない。

  仮説3「人口統計指紋の偶然一致」
    残る説明はこれである。すなわち、本文の偶然期待（1.9対）が過小である。
    視野の一致による検証はできない。FairVision は点別視野を配布しておらず、
    平均偏差は一致の条件そのものなので、定義上すべて一致する。
    → 改訂では「人口統計のみの一致は候補であって確認された重複ではない」
       という現在の扱いを維持し、その根拠として上の3検定を補遺に載せる。
